- commands.html: Example bot commands
- about.html: About page
- support.html: Support page
- style.css: Shared styling and responsive layout

HOW TO USE
1. Keep all six files in the same folder.
2. Open index.html in your browser to preview the website.
3. Search all files for YOUR_INVITE_LINK and YOUR_SUPPORT_SERVER.
4. Replace those placeholders with your real Discord invite links.
5. The commands page contains example commands only; update it to match your actual bot.

This is a static website. It does not connect to the bot or automatically verify commands.
